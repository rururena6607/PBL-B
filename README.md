# 音声解析による設備稼働状況可視化ツール

![Python](https://img.shields.io/badge/Python-3.x-blue?logo=python)
![License](https://img.shields.io/badge/License-MIT-green)
![Platform](https://img.shields.io/badge/Platform-Windows-lightgrey?logo=windows)

大学PBL授業の企業連携プロジェクトとして開発。  
エアレス塗装機の**録音データから稼働回数を自動カウント**し、設備の稼働状況を可視化するデスクトップアプリケーション。

---

## 背景・課題

工場では設備がいつ・何回稼働したかを人が目視・手作業で記録していた。  
これを**音声解析によって自動化**し、稼働ログの取得コストをゼロにすることを目指した。

---

## 機能

| 機能 | 説明 |
|------|------|
| 音イベント一括解析 | フォルダ内の全WAVファイルを自動処理し、稼働回数をリスト表示 |
| 波形ビューア | エンベロープ・動的しきい値・検知ピークをリアルタイムで描画 |
| CSV出力 | 日時付きファイル名で解析結果を一括エクスポート |
| WAV分割 | 長時間録音を任意の分数単位に分割 |

---

## 技術的工夫

### 1. 15〜20kHz 帯域抽出
エアレス塗装機の動作音に固有の周波数帯をバンドパスフィルタで抽出し、環境ノイズの影響を最小化。

### 2. クレストファクターによる自動ノイズ判定
エンベロープのピーク/平均比（クレストファクター）が閾値未満の場合、定常ノイズと判定してスキップ。手動設定なしで録音環境の差異を吸収。

### 3. 局所平均による動的しきい値
固定しきい値ではなく録音の局所的な音量変化に追従するしきい値を算出。長時間録音での音量ドリフトに対応。

### 4. 複数WAVフォーマット対応
現場のICレコーダーが出力する8/16/24/32bit WAVを多段フォールバックで読み込み。

## 検証

実際の工場録音データを用いてアルゴリズムの精度を検証済み。

## 技術スタック

- **言語**: Python 3
- **GUI**: tkinter
- **信号処理**: scipy (butter filter, sosfiltfilt, find_peaks)
- **数値計算**: numpy
- **描画**: tkinter Canvas（matplotlibなし・軽量実装）

## インストール

```bash
git clone https://github.com/rururena6607/PBL-B.git
cd PBL-B
pip install -r requirements.txt
```

## 使い方

```bash
python main3.py
```

1. **音イベント解析タブ** → フォルダ選択 → 一括解析開始
2. ファイルをクリックすると波形・しきい値・検知ピークを表示
3. CSV保存ボタンで結果をエクスポート
